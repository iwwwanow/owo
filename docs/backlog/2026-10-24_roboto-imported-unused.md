# Roboto импортируется, но не используется

`web/static/css/font.css` импортирует Roboto (400/700) из Google Fonts, но ни одно правило не ссылается на `font-family: "Roboto"`: всё задаётся через `* { font-family: "Roboto Condensed", … }`. Получается лишний сетевой запрос на каждой странице. Скорее всего Roboto задумывался для `p` — для основного текста обычная ширина читается легче, чем condensed. Решить: либо назначить Roboto для `p` (и проверить, как это смотрится рядом с condensed-заголовками), либо убрать импорт.
