# code { font-size: 1.6em } компаундится во вложенных тегах

В `web/static/css/font.css` у `code` стоит `font-size: 1.6em`. Это рассчитано на случай, когда `code` лежит прямо в блоке с корневым размером 10px (`:root { font-size: 62.5% }`): как в шаблоне `code.component`, где `<code>` вставляется прямо в `.grid__right-content`, или внутри `pre`. Тогда получается 16px. Но `em` считается от родителя, поэтому inline-код внутри `p` (1.6em) становится 1.6 × 16 = 25.6px, внутри h4/h5/h6 — 22.4px. На страницах с html/md-контентом, где есть `<p>…<code>…</code>…</p>`, код получается заметно крупнее текста.

Вариант фикса: размер кода задать на контейнерах, а сам `code` оставить относительным. Например, `pre { font-size: 1.6rem }` и `code { font-size: 1em }`; для голого `code` из `code.component` — обёртка или отдельный класс с `1.6rem`.

Связанные заметки про шрифты: `2026-10-24_roboto-mono-not-loaded.md`, `2026-10-24_roboto-imported-unused.md`.

В uiu (iwwwanow/uiu) это расхождение уже поправлено в блоке «deviations» в конце `owo.css`.
