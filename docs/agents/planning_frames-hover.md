# Frames Hover Effect — Planning

## Что делаем

При наведении на любую `.card__wrapper` на странице:

1. Весь фон страницы уходит в блюр
2. Поверх страницы появляется оверлей с рамой
3. Картинка карточки вписывается во **внутренние** размеры рамы
4. Слева от рамы — текстовый блок в стиле «американского канона»
5. Всё с небольшой задержкой и плавными переходами

---

## Компоненты эффекта

### 1. Блюр фона

- Весь `.wrapper` (или `body`) получает `filter: blur(Xpx)` при ховере
- Реализуется через CSS-класс, который JS добавляет/убирает
- Активная карточка из блюра исключается

### 2. Рама

- Файл: `/.meta/assets/frame-1.png?static`
- PNG с **прозрачным** центром — картинка карточки лежит под рамой через z-index
- Рамка позиционируется в оверлее поверх картинки
- Внутренние отступы (FRAME_INSET) — проценты от итогового размера рамы. Примерная оценка по PNG: ~13% со всех сторон, уточняется визуально при реализации
- Рама portrait (~3:4). Карточки могут быть landscape — рама растягивается, небольшое искажение допустимо
- Будущее: массив путей к рамам + рандомайзер при каждом ховере

### 3. Картинка внутри рамы

- `<img>` или `<picture>` вырезается из карточки (или дублируется)
- Вписывается в **inner rect** рамы: `object-fit: cover`, размеры = innerWidth × innerHeight рамы
- Позиционируется абсолютно внутри оверлея поверх прозрачного центра рамы

**Вычисление innerRect:**
```
frameW = итоговая ширина рамы на экране
frameH = итоговая высота рамы на экране

innerRect = {
  top:    frameH * FRAME_INSET.top,
  right:  frameW * FRAME_INSET.right,
  bottom: frameH * FRAME_INSET.bottom,
  left:   frameW * FRAME_INSET.left,
}

innerWidth  = frameW - innerRect.left - innerRect.right
innerHeight = frameH - innerRect.top  - innerRect.bottom
```

Константы `FRAME_INSET` подбираются вручную под конкретный PNG рамы.

### 4. Текстовый блок

Структура (слева от рамы, по вертикали центрирован):

```html
<div class="frame-overlay__text">
  <h1>{название}</h1>
  <p>{описание}</p>
  <div class="frame-overlay__price">
    <h2 class="frame-overlay__price-old">{старая цена}</h2>  <!-- зачёркнутый, жёлтый -->
    <h2 class="frame-overlay__price-new">{новая цена}</h2>   <!-- красный -->
  </div>
</div>
```

**Стили:**
- Использовать родные теги `h1`, `p`, `h2` — унаследуют шрифт, размер, weight из глобального CSS
- `frame-overlay__price-old`: `text-decoration: line-through`, цвет `var(--js)` (#f0db4f) из палитры сайта
- `frame-overlay__price-new`: цвет `var(--RED)` (#f00)

**Источник данных — фаза 1 (сейчас):**

Все данные — константы прямо в скрипте:

```js
const CARD_DATA = {
  title: 'Название картины',
  description: 'Описание работы',
  priceOld: '30 000 ₽',
  priceNew: '18 000 ₽',
}
```

Название дополнительно берётся из `.card__text-header` карточки (чтобы хотя бы оно было динамическим).

**Источник данных — фаза 2 (позже):**

Кирилл переносит данные на страницу картины (вероятно через `data-*` атрибуты на карточке или `.meta/` директории). Скрипт обновляется под новый источник.

### 5. Оверлей-контейнер

Один `<div id="frame-overlay">` вставляется в `<body>` при инициализации скрипта, скрыт по умолчанию.

```html
<div id="frame-overlay">
  <div class="frame-overlay__text">...</div>
  <div class="frame-overlay__frame-wrap">
    <img class="frame-overlay__frame-img" src="/.meta/frame.png?static" />
    <img class="frame-overlay__inner-img" />   <!-- картинка карточки -->
  </div>
</div>
```

На mouseenter карточки: наполнить данными + показать.
На mouseleave: скрыть.

## Размер оверлея и пропорции рамы

Рама **всегда сохраняет пропорции** PNG (no stretch).

**Горизонтальный режим** (grid > 2 колонок):
- Ширина рамы = ширина карточки
- Высота рамы = ширина × (frameNaturalH / frameNaturalW)

**Вертикальный режим** (grid ≤ 2 колонок / tile):
- Ширина рамы = ширина экрана (100vw минус отступы)
- Высота — по пропорции

Определение режима: проверяем `grid.classList.contains('grid--hidden')` или считаем количество колонок через `getComputedStyle`.

Текстовый блок должен гарантированно помещаться рядом с рамой — при необходимости ограничить максимальную ширину рамы, чтобы осталось место для текста.

## Мобайл / тач

- На тач-устройствах (`'ontouchstart' in window`) — вместо `mouseenter/mouseleave` используем `touchstart` для открытия модалки
- Тап за пределами оверлея закрывает его
- Задержка на тач не нужна (реакция мгновенная)
